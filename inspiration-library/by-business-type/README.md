# 🏷️ By business type — index files, not folders

These files **point** at cards in [`../recipes/`](../recipes/). They hold no images and no card text, so a
technique that suits three business types is listed three times and **stored once**.

Business type governs **register and taste**, not technique. A fragrance house and a 3D printing lab can use
the identical lighting move and should still not look alike. So type is a filter you apply when choosing,
never a wall you file behind. That is why these are indexes and not folders: filing
`big-word-poster-hook` under "creative agency" would hide it from the coffee brand that needs it.
