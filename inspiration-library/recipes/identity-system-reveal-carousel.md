# The identity-system reveal carousel

> ⭐ **THE signature move on this board.** The direct fix for the "bland empty bottle" problem.

| | |
|---|---|
| **business type** | any (built for creative-agency, works for every product brand) |
| **product type** | physical-product |
| **format** | carousel, 5-7 slides |
| **technique** | mockup, collage, typography |
| **seen in** | @offsetmedia.lb (Koi Cafe, Melange, Finnlux) |
| **screenshots** | [`sources/offset-media/`](../sources/offset-media/) |

**What it is:** a carousel that unveils a full fictional brand as ONE complete system: hook → big logo lockup → logo on colour → **brand-board collage** → individual mockups (cup, coffee bag, bread bag, business cards, letterhead, website on a laptop).

**Why it works:** it does NOT show one lonely empty object. It shows a whole world (name + logo + colours + fonts + pattern + real-world mockups), so the prospect *sees the transformation they would buy*.

### ✅ STEAL
The structure (hook → logo → board → mockups) and the principle: sell the whole system, not one image.

### 🔄 ADAPT
Use OUR demo houses (a demo house, a demo house, the demo brand, a demo jewellery house). the agency's own wrapper slides (hook + CTA) stay in the agency's palette; the demo brand's slides use the DEMO brand's own palette (see its `product.md`). More cinematic lighting than Offset's flat-lit mockups.

### 🚫 DON'T
Copy Koi's olive/tan palette, the fish mark, "Best coffee in town," or the checkerboard.
