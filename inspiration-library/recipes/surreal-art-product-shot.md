# Surreal / art product shot

> One per set, at most.

| | |
|---|---|
| **business type** | any |
| **product type** | physical-product |
| **format** | single image |
| **technique** | photography, 3d-render |
| **seen in** | @yourmediasa ("melting coffee"; frozen-splash pour) |
| **screenshots** | [`sources/yours-media/`](../sources/yours-media/) |

**What it is:** one bold art-directed hero, such as melting coffee over a ceramic tumbler or a frozen splash.

**Why it works:** a single art shot per set is a strong craft signal.

### ✅ STEAL
The idea of exactly one art-directed hero per set.

### 🔄 ADAPT
Tune it premium, not gimmicky.

### 🚫 DON'T
Make it the whole set, or let the effect obscure the product. **Product accuracy always wins** (LAW 2: a wrong product is deleted).
