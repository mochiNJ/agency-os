# The comment-CTA idea loop

| | |
|---|---|
| **business type** | manufacturing-3d-printing, any made-to-order brand |
| **product type** | physical-product |
| **format** | video caption |
| **technique** | caption-craft |
| **seen in** | @nk3dlab (TikTok) |

**What it is:** end the caption with a direct ask: *"comment what to print next!"*

**Why it works:** it converts viewers into a free product-idea engine and lifts comment count, which is the
weakest metric on save-heavy maker posts. For a make-anything business the answers are literal demand
signal.

### ✅ STEAL
The closing ask, phrased as a genuine question rather than "engage with us."

### 🔄 ADAPT
Perfect for a client's custom-anything positioning: the replies become the content calendar. Log good answers
into the client's `creative-decisions-log.md` so they survive past the post.

### 🚫 DON'T
Ask and then never print one. The loop only works if a suggestion visibly gets made.
