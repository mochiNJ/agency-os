# One asset, two treatments

| | |
|---|---|
| **business type** | any |
| **product type** | any |
| **format** | two slides in a carousel |
| **technique** | collage, typography |
| **seen in** | @yourmediasa ("The Life of a Giant Bean") |
| **screenshots** | [`sources/yours-media/`](../sources/yours-media/) |

**What it is:** show the SAME infographic two ways: once on a clean white card, then full-bleed over a map or texture.

**Why it works:** it proves versatility cheaply, from a single asset.

### ✅ STEAL
The two-treatment reveal. It demonstrates range without doubling the production.

### 🔄 ADAPT
Use our demo house's own story as the infographic.

### 🚫 DON'T
Let the second treatment hurt legibility. Text over texture still obeys `system/text-size-rules.md`.
