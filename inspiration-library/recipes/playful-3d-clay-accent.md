# Playful 3D / clay illustration accent

> Use sparingly. the agency leans cinematic, not cute.

| | |
|---|---|
| **business type** | any |
| **product type** | any |
| **format** | single slide |
| **technique** | 3d-render, typography |
| **seen in** | @offsetmedia.lb (desk lamp "BRAND"; pink phone) |
| **screenshots** | [`sources/offset-media/`](../sources/offset-media/) |

**What it is:** simple, characterful 3D or claymation-style props as the visual metaphor, on a flat brand-colour background, with hand-script annotations.

**Why it works:** it adds warmth and personality, avoids cheap-feeling stock, and the metaphor carries the message.

### ✅ STEAL
One clean 3D metaphor prop on a brand-colour field plus a small handwritten annotation.

### 🔄 ADAPT
An occasional lighter-touch educational slide, never the whole feed.

### 🚫 DON'T
Overuse it. It reads junior if every post is a cartoon prop.
