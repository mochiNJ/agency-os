# The model as the message

> Scale reference, not a craft reference. Superside is a 118K-follower company, a different tier from the boutique accounts on this board.

| | |
|---|---|
| **business type** | creative-agency, any AI-powered service |
| **product type** | service |
| **format** | single image or carousel |
| **technique** | typography, charts |
| **seen in** | @supersidehq (AI-tooling posts, "Superside it" launch) |

**What it is:** posts that sell the SYSTEM (how the managed process works) as content in its own right, not just finished portfolio pieces. A recurring format gets formally named and launched as its own announcement post.

**Why it works:** it proves process and builds a memorable, repeatable content event, instead of posting only finished results with no visible "how." For an AI-powered studio it also fights the "faceless software" read.

### ✅ STEAL
Alternate "how the engine actually works" posts with finished-world posts. Formally launch a named recurring format as its own announcement moment, not a quiet first example.

### 🔄 ADAPT
Our process post shows send-assets → AI engine → human QC → delivered world, in our own identity and voice.

### 🚫 DON'T
Copy Superside's enterprise register. It assumes a bigger-budget buyer than ours.
