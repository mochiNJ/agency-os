# The full spec-sheet caption

> Decoded 2026-09-06 from a client's onboarding research, where it had sat undecoded since 2026-07-17.

| | |
|---|---|
| **business type** | manufacturing-3d-printing, any maker/craft brand |
| **product type** | physical-product |

**What it is:** the caption is a complete spec sheet: designer credit, model source, filament brand, layer height, supports yes/no, infill %, wall count, printer model, then the link line.

**Why it works:** in a maker niche the spec sheet IS the value. It converts a passive viewer into a saver: both reference posts pulled **over 23,000 saves**, far out of proportion to their comment counts.

### ✅ STEAL
The spec-sheet caption structure, and crediting the model designer by name.

### 🔄 ADAPT
a client states only what its `product.md` actually records. **Anything not in that file is UNKNOWN and is never stated publicly** (Rule 7). Print time is display-only; weight is never shared.

### 🚫 DON'T
Invent a spec to fill the template. A wrong spec in a maker niche destroys credibility instantly.
