## 🥇 THE GOLDEN RULE
**Steal the technique. Adapt it to THIS client and THIS product. Never clone the source.**
Copy the *how* (composition, lighting, mood, pacing, caption energy). Never the *what* (their logo, their
exact colours, their literal subject).

## Adding a card

1. File the screenshot under the account it came from, in [`../sources/`](../sources/). One home, forever.
2. Write one card here, named for **the technique**, never for the brand it came from.
3. Fill the tag table at the top so the card can be found from any angle.
4. Add a row above, and a line in the matching [`../by-business-type/`](../by-business-type/) index.

**Name the card for the move, not the source.** `big-word-poster-hook.md`, never `offset-media-post-3.md`.
A card named after its source can only ever be found by someone who already knows the source.
