# Lifestyle → in-hands → macro

> Decoded 2026-09-06 from a client's onboarding research, where it had sat undecoded since 2026-07-17.

| | |
|---|---|
| **business type** | manufacturing-3d-printing, any made object |
| **product type** | physical-product |
| **format** | carousel, 4 slides |
| **technique** | photography |
| **seen in** | @nuuuuuage-style IG carousel ("INTRODUCING NUUUUUUAGE 1.0") |

**What it is:** a four-slide carousel in three beats. Slide 1 is a wide lifestyle scene, the product in a
styled room in real use. Slide 2 is the product held in hands, giving scale and human touch. Slides 3 and 4
are tight macro close-ups in soft warm window light with shallow depth of field.

**Why it works:** it answers the three questions a buyer actually has, in order: *where does this live?*,
*how big is it?*, *is it well made?* The macro shots **celebrate the print-layer texture instead of hiding
it**, which turns the manufacturing method from an apology into a craft signal.

### ✅ STEAL
The three-beat order (wide → in-hands → macro), warm natural window light, and the decision to show the
texture rather than conceal it.

### 🔄 ADAPT
a client's client wish was explicitly *"nothing should look cheap or 3D printed"* and *"never AI-fake"*. This
format satisfies both with real photography in a lived-in setting. Use warm staging, not a dark tech-void
background, on every post.

### 🚫 DON'T
Stage it so tidily that it stops looking real. Real hands and a real room are the point.
