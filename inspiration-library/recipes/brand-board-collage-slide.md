# The brand-board collage slide

> ⭐ This is the "identity kit" slide every demo house needs.

| | |
|---|---|
| **business type** | any |
| **product type** | physical-product |
| **format** | single slide (inside a carousel) |
| **technique** | collage, typography, mockup |
| **seen in** | @offsetmedia.lb (Koi slide 1; Melange; Finnlux) |
| **screenshots** | [`sources/offset-media/`](../sources/offset-media/) |

**What it is:** ONE slide that is a tidy grid: big logo tile + **hex-code colour swatches shown as labelled chips** + **named font specimens** + a repeating pattern tile + one or two mockup photos. Rounded-corner tiles, small circular logo badge floating over a seam.

**Why it works:** in a single glance it screams "this is a real, considered brand." The visible hex codes and font names read as *proof of craft*, like a real brand guideline.

### ✅ STEAL
The grid-of-tiles composition, showing real hex chips + named fonts, and the floating badge.

### 🔄 ADAPT
Build it per demo house with THAT house's palette and our chosen fonts; keep our studio lighting on the mockup photos.

### 🚫 DON'T
Reuse their exact tile colours or the fish/coffee motifs.
