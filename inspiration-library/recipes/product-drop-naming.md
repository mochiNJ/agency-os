# Product-drop naming and versioning

| | |
|---|---|
| **business type** | manufacturing-3d-printing, any maker or small-batch brand |
| **product type** | physical-product |
| **format** | any |
| **technique** | caption-craft, typography |
| **seen in** | @nuuuuuage-style IG carousel ("NUUUUUUAGE 1.0") |

**What it is:** name the product line like a real product launch and give it a version number, then announce
it as a drop: *"Introducing NUUUUUUAGE 1.0."*

**Why it works:** a version number implies there will be a 2.0, which creates a collectible feeling and
turns a one-off print into a product line. It costs nothing and instantly reads more serious than "new item."

### ✅ STEAL
The naming plus the version, and the word "introducing" framing it as an event.

### 🔄 ADAPT
a client already has named pieces (the client's product statue, NEST, the plant pot). Give each a real name in its
`product.md` and treat every new one as a drop. **Playful custom typography is allowed when the product
itself is playful**, and only then.

### 🚫 DON'T
Version something that will never have a second version. An unfulfilled 1.0 is worse than no number.
