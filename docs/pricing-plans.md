# Pricing Plans: Free vs Paid Setup

This agency system runs on two tiers. Start free, upgrade when you're ready to scale.

---

## FREE PLAN ($0/month)

**What you get:**
- Image generation via mcp-image (powered by Google Gemini — free API key from aistudio.google.com)
- Social media scheduling via Postiz (self-hosted, free)
- All 16 agent instructions
- All skills via skillkit (free)
- SEO/AEO audits via claude-seo (free)
- Full content pipeline (copy → humanizer → QC)

**Limitations:**
- Image quality is good but not production-grade product photography
- Postiz requires self-hosting (runs locally)
- No video generation
- No paid ads automation

**Best for:** Getting started, testing the system, solo operators, early-stage clients

---

## PAID PLAN (~$90-190/month total)

**Additional tools unlocked:**

| Tool | Cost | What it adds |
|---|---|---|
| Higgsfield MCP | ~$30-50/mo | Cinematic video generation, product animation, Seedance 2.0, UGC presets |
| Claid.ai MCP | ~$30-60/mo | Professional product photography, preserves logos and shapes perfectly |
| Ayrshare MCP | ~$29/mo | Post to 13+ platforms simultaneously with scheduling |
| Composio MCP | Free tier + paid | 1,000+ tool connections (Analytics, WhatsApp, Gmail, TikTok, LinkedIn, etc.) |
| Meta Ads MCP | Free | Official Meta API — 29 tools for campaign creation, monitoring, optimization |

**What the paid plan unlocks:**
- Production-grade product photography (Claid.ai)
- Short-form video generation (Higgsfield)
- One-click publish to 13+ platforms (Ayrshare)
- WhatsApp Business automation (Composio)
- Full paid ads management (Meta Ads MCP)
- Cross-platform analytics (Composio → Google Analytics, Search Console)
- Email automation (Composio → Mailchimp or Gmail)

**Best for:** Active client work, agencies serving multiple clients, full automation

---

## Upgrade Path

1. Start with free plan — get the full pipeline working
2. Add Ayrshare ($29/mo) — first upgrade, removes manual publishing
3. Add Composio (free tier) — unlocks WhatsApp, analytics, email integrations
4. Add Claid.ai — when product photography quality becomes a bottleneck
5. Add Higgsfield — when clients need video content at scale
6. Add Meta Ads MCP (free) — when clients are ready for paid advertising

---
